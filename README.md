# E-Shop React E-Commerce Application

E-Shop is a user-friendly React-based e-commerce application where customers can browse products, add items to their cart, and place secure online orders with a simple checkout process. This project is built using **React**, **React-Bootstrap**, **Redux Toolkit**, and modular reusable components for a clean and maintainable structure.

---

## 🚀 Features

* **Product Browsing** – Users can view a list of products with essential details.
* **Responsive UI** – Built with React-Bootstrap for seamless performance across devices.
* **Cart Management** – Add, remove, and update quantities of items in the cart.
* **Structured Component Architecture** – Clean folder structure for scalability.
* **Reusable Components** – Navbar, Footer, Banner, Loader, etc.
* **State Management** – Redux Toolkit slice for managing cart state.

## 🛠️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/your-repo/e-com-app.git
cd e-com-app
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm start
```
